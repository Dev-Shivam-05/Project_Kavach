# ADR-008 — MLS (RFC 9420) is the end-to-end encryption protocol

Status: Accepted · 2026-08-04 · **deferred in phase by ADR-021** — the protocol choice stands, the ship date moved

## Context

The server must never be able to read precise location, health data, audio,
messages or documents (threat T3, PRD §10.1; data Class A, PRD §10.2). The
primitive this system actually needs is not a pairwise session: it is a **group**
— several people, several devices each, membership that changes when a phone is
lost, a member turns 18, or a temporary member's contract expires.

## Decision

MLS, via OpenMLS. Ciphersuite
`MLS_128_DHKEMX25519_AES128GCM_SHA256_Ed25519` — the mandatory-to-implement
suite, hardware-accelerated everywhere. TreeKEM gives O(log n) group operations
with forward secrecy and post-compromise security. The control plane implements
the Delivery Service and provides the per-group total order on Commits that MLS
requires (docs/02 §2.4.4).

**Never invent cryptography.** This decision is as much about what is forbidden
as what is chosen.

## Alternatives

- **A Signal-protocol clone** — rejected. Pairwise sessions fanned out to a
  group is exactly the N² device-management problem MLS was standardised to fix.
- **A bespoke scheme** — rejected categorically. Not a schedule decision.
- **No E2EE** — rejected. It would make the server the single richest target in
  the family's life, and it is the promise the family agreement is built on.

## Consequences

- MLS is 8–14 weeks of work including the Delivery Service, epoch recovery and
  key transparency — not the 21 days the PRD's schedule assumed (finding F-08).
  Putting it on the critical path is the single most likely cause of never
  reaching the Phase 1 gate, which is why **ADR-021 defers it** behind a scheme
  byte. This ADR is not superseded; the protocol is still the destination.
- A total order on Commits per group makes the Delivery Service a correctness
  dependency, not just a relay: two concurrent commits must produce one epoch
  and one `KV-2003`, never a fork.
- Post-quantum is explicitly out of v1. Harvest-now-decrypt-later matters for a
  30-year document vault, not for incident data with a 90-day life. Revisit in
  2028 with hybrid X-Wing (PRD §10.3).
- Key transparency is not optional decoration: without an append-only log of
  device-key additions that clients verify, a compromised server can silently
  add a device to the group. That is the classic attack on every E2EE system and
  it is Phase 2 work.

## Implementation

Not implemented. What exists today is the migration seam that lets it arrive
without a flag day:

- `mobile/src/crypto/index.ts` — `SCHEME_MLS = 0x02` reserved; every ciphertext
  carries the scheme byte
- `docs/02-System-Architecture.md` §2.4.1, §2.4.4 — the phasing table and the
  Delivery Service assignment
- `docs/03-Implementation-Guide.md` §3.5 — the MLS migration workstream, Phase 2
- ADR-021 — the interim scheme and its cost
